# Rodando por CABA

Proyecto inicial de una página personal sobre rollers y encuentros para patinar en la Ciudad Autónoma de Buenos Aires.

## Tecnologías utilizadas

- HTML para crear la estructura de la página.
- CSS para agregar colores, tamaños, menú y diseño responsivo.

## Estructura del proyecto

```text
Blog/
├── index.html
├── README.md
├── assets/
│   └── rollers-ilustracion.svg
└── css/
    └── styles.css
```

## Cómo ver el proyecto

1. Abrir la carpeta `Blog`.
2. Hacer doble clic en el archivo `index.html`.
3. El sitio se abrirá en el navegador.

## Próximos pasos

Más adelante se puede agregar JavaScript básico para practicar interacciones simples.

## Formulario

El formulario es visual y sirve para practicar HTML. Todavía no guarda ni envía datos, porque el proyecto no usa JavaScript ni un servidor.
